# Roselle 🌺

A modern period & cycle tracking app with personalized nutrition recommendations.

## Features
- Google Sign-in authentication
- Period logging with flow intensity
- Cycle prediction based on historical averages
- Symptom tracking (cramps, mood, energy, and more)
- Basal Body Temperature (BBT) charting
- Phase-based nutrition recommendations
- Visual calendar with color-coded cycle phases
- Dark/light theme support

## Tech Stack
- React + Vite
- Supabase (Auth + Database)
- Recharts
- date-fns
- Lucide React icons
- Netlify hosting
